release request

게시 대상 candidate를 골라 release request를 요청하고, 다른 관리자가 승인합니다. 승인 후 production 게이트는 수동 dispatch로 실행합니다.

수동 dispatch 필요

승인된 요청은 아래 명령의 경로 표시를 실제 evidence 파일로 바꾼 뒤 실행합니다.

gh workflow run datapack-release.yml \
  --ref main \
  -f mode=production-publish \
  -f targetChannel=production \
  -f modeArgs='{"buildSpecPath":"<빌드 스펙 경로>","releaseRequestId":"<릴리스 요청 ID>","releaseRequestPath":"<릴리스 요청 파일 경로>","androidEvidencePath":"<Android 증거 경로>","strictRouteRegressionPath":"<경로 회귀 증거 경로>"}'

candidate 등록: 현재 candidate 생성·등록 경로는 없습니다. 이 화면은 datapack_candidates에 이미 등록된 PROMOTED 행만 읽습니다. 등록되지 않은 candidate를 추정하거나 DB에 직접 넣지 말고 release request 생성을 중단합니다.
