쉬운 지하철 개인정보처리방침

시행일: 2026년 7월 16일

쉬운 지하철(easysubway)은 교통약자가 도시철도를 더 쉽게 이용할 수 있도록 역, 시설, 경로, 신고 기능을 제공합니다. 이 문서는 앱에서 처리하는 개인정보, 보관 기준, 삭제 요청 방법, 문의 창구를 설명합니다.

SUBWAY와 선택형 ITX-청춘 경로 검색

SUBWAY 경로 검색은 단말 안에서만 처리하며 서버로 전송하지 않습니다. ITX-청춘 경로 검색은 사용자가 직접 선택할 때만 서버 기능을 사용하며, 사용자 행동을 tracking에 사용하지 않습니다.

ITX 경로 세션을 만들 때 앱은 Google Play Integrity에 requestHash를 보내고, Google은 무결성 확인을 위해 앱 package·version·certificate, 단말에서 로그인된 Google Play 계정의 license 상태와 기기 attestation 정보를 암호화해 처리합니다. 이 정보는 Google의 Play Integrity 고정 보관 정책을 따르며 Google이 제3자에게 전송하지 않습니다. 그 뒤 앱은 integrityToken과 128-bit clientNonce를 쉬운 지하철 backend로 전송하고, backend는 검증을 위해 raw integrityToken을 Google Play Integrity decode API로 전송합니다. 쉬운 지하철 backend의 경로 세션·상태는 사용자·기기·계정 ID와 연결하지 않지만, 위 Google 처리 범위는 이 backend 비연결 경계와 구분됩니다.

backend는 raw integrityToken을 저장하지 않고, 검증 후 발급한 Route V2 세션 token의 SHA-256, scope, issuedAt, expiresAt, requestCount를 논리적으로 10분 동안, raw nonce 대신 nonce SHA-256을 논리적으로 2분 동안 저장합니다. 정상 동작 중 만료 데이터는 기본 5분 주기 purge로 물리 삭제하므로 세션은 발급 후 약 15분 이내, nonce 해시는 수신 후 약 7분 이내 삭제됩니다. ITX 경로 요청의 실제 JSON에는 originStationId, destinationStationId, departureTime, mobilityType, mobilityPreset, constraintMode, useRealtime, maxTransfers, alternativeCount가 포함됩니다.

경로 상태 DB에는 routeStateId, 출발역·도착역 ID, backend가 정한 transport scope, 요청 출발 시각, 계산된 itinerary JSON, timetable artifact ID, createdAt, plannedArrivalAt, expiresAt을 저장합니다. mobilityPreset은 itinerary JSON의 보행 구간 appliedPreset에도 포함되므로 이 이동 조건 처리는 ephemeral로 표시하지 않습니다. 논리 보관 기간은 min(createdAt+6h, max(createdAt+30m, plannedArrivalAt+30m))로 생성 시각부터 최소 30분, 최대 6시간이며, 정상 동작 중 물리 삭제는 expiresAt 뒤 5분 이내입니다.

backend는 raw integrityToken, raw nonce, Integrity payload·verdict를 DB에 저장하거나 로그에 남기지 않으며, Route V2는 raw 검색어와 좌표를 요청으로 보내거나 저장하지 않습니다. 별도로 gateway는 요청 제한을 위해 IP의 이진 표현인 $binary_remote_addr와 Bearer 세션 token이 든 $http_authorization을 Nginx shared memory key로 처리합니다. 이 상태는 요청이 끝난 뒤에도 shared memory에 남을 수 있어 ephemeral 처리로 분류하지 않습니다. 고정 TTL은 없으며, zone 메모리가 부족할 때 LRU 방식으로 퇴출되고 최종적으로 gateway process 또는 shared-memory zone 수명 종료 시 삭제됩니다. 설정의 10m은 보관 기간이 아니라 zone 용량입니다. 이 key 값은 DB나 access log에는 저장하지 않습니다. 제한 응답 로그에는 고정 event·scope·status만 남고 key 값은 포함하지 않습니다. 세션과 경로 응답에는 private, no-store cache 정책을 적용합니다.

민감한 상태 정보

쉬운 지하철은 장애, 임신, 질병, 부상 여부를 증명하는 서류나 진단정보를 요구하지 않습니다. 앱은 사용자가 직접 선택한 이동 조건을 경로 안내에만 사용하며, 광고나 추적 목적으로 사용하지 않습니다.

보관, 전송, 파기

즐겨찾기, 최근 검색, 앱 설정, 신고 초안, 설치된 이동 정보 기록은 기본적으로 사용자 기기에 보관됩니다. 신고 제출, 선택형 ITX-청춘 경로 검색, 삭제 요청처럼 네트워크 전송이 필요한 경우 HTTPS를 사용합니다. 보관 목적이 끝나거나 삭제 요청 처리가 완료된 개인정보는 복구하기 어렵게 삭제하거나 식별 가능성을 줄입니다.

제3자 제공, 처리 위탁, 추적

쉬운 지하철은 개인정보나 민감정보를 판매하지 않습니다. 광고 목적의 tracking을 하지 않으며, 신고 사진과 위치 정보는 앱 기능 제공과 신고 검토 목적에만 사용합니다. 사용자가 출구 도보 길안내를 명시적으로 누른 경우에만 현재 위치 시작 좌표와 목적지 좌표를 카카오맵 앱/웹에 전달하며, 앱 서버에 저장하지 않습니다. 서비스 운영에 필요한 범위에서만 Cloudflare, Oracle Cloud Infrastructure, Google Play Console 같은 인프라와 스토어 운영 도구를 사용할 수 있으며, 이 경우 해당 사업자는 서비스 제공, 보안, 저장, 배포, 진단 목적의 처리만 수행합니다.

아동의 개인정보

쉬운 지하철은 만 14세 미만 아동을 주 대상으로 하지 않습니다. 만 14세 미만 아동의 개인정보 처리 요청이 확인되면 법정대리인 확인 등 필요한 절차에 따라 처리합니다.

안전성 확보 조치

개인정보는 접근 권한을 제한하고, 운영 로그에는 신고 receipt token, 사진 원본, 서명된 업로드 URL, 저장소 자격 증명을 남기지 않도록 관리합니다. 관리자 화면은 인증된 운영자만 접근할 수 있으며, 네트워크 전송에는 HTTPS를 사용합니다.

변경 안내

개인정보 처리 내용이 바뀌면 이 페이지의 시행일과 내용을 갱신합니다. 중요한 변경은 앱 또는 스토어 안내에 반영합니다.
