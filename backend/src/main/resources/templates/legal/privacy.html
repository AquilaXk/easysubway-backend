쉬운 지하철 개인정보처리방침

개정 공고일: 2026년 10월 9일 · 시행일: 2026년 10월 16일

쉬운 지하철(easysubway)은 교통약자가 도시철도를 더 쉽게 이용할 수 있도록 역, 시설, 경로, 신고 기능을 제공합니다. 이 문서는 앱에서 처리하는 개인정보, 보관 기준, 삭제 요청 방법, 문의 창구를 설명합니다.

1. 개인정보 처리방침의 적용

이 방침은 아퀼라 소프트웨어가 운영하는 쉬운 지하철 앱과 연결된 백엔드 기능에 적용됩니다. 외부 지도와 공공데이터 제공처 등 다른 사업자의 서비스에는 해당 사업자의 방침이 적용됩니다.

2. 처리하는 개인정보 항목과 목적

항목 처리 목적 보관 기준
현재 위치 가까운 역 검색, 시설 신고 위치 확인, 외부 지도 도보 길안내 주변 역 검색과 출구 도보 길안내 시작 좌표는 저장하지 않음. 시설 신고 좌표는 운영 데이터에서 접수일부터 최대 1년, 제한된 운영 백업에서 백업 생성일부터 30일 보관 후 자동 삭제 또는 익명화
역 검색어, 최근 검색, 즐겨찾기 역 검색, 경로 안내, 자주 보는 역·시설·경로 표시 기기 또는 서버에 저장된 값은 사용자가 삭제하거나 데이터 삭제를 요청할 때까지 보관
이동 조건 선택값 계단 회피, 엘리베이터 우선 등 접근성 경로 안내 사용자가 변경, 초기화, 삭제 요청할 때까지 보관
경로 요청 식별자, 출발·도착역 ID, 출발 기준, 시간·실시간 정책, 이동 조건, 환승·대안 수 제한 서버 경로 검색 요청과 계산 결과는 별도 검색 이력으로 저장하지 않습니다. 세션 검증용 해시 상태는 제4항의 기준을 따릅니다.
시설 신고 내용, 사진, 접수 식별 정보 시설 고장, 공사, 위치 오류 신고 검토와 처리 상태 안내 신고 내용과 접수 식별 정보는 운영 데이터에서 접수일부터 최대 1년, 제한된 PostgreSQL 백업에서 생성일부터 30일 보관 후 자동 삭제 또는 익명화. 신고 사진은 운영 object에서 접수일부터 최대 1년 보관하며 별도 백업 사본을 만들지 않음
충돌 진단 정보: 충돌 스택 트레이스, 예외 유형과 오류 종류 코드, 오류가 발생한 기능 구분, HTTP 상태 코드, 치명 여부, 발생 시각, 기기 모델·OS 이름과 버전·CPU 구조, 기기 상태(메모리와 저장 공간 용량, 화면 방향, 앱이 백그라운드에 있었는지 여부), 앱 버전, 앱 설치별로 부여되는 익명 설치 식별자(Crashlytics 설치 UUID, Firebase 설치 ID)와 세션 식별자 앱 충돌 원인 분석과 서비스 안정성 개선 Google(Firebase Crashlytics)의 보관 기준에 따라 수집일부터 90일 보관한 뒤 Google의 삭제 절차가 시작됨. 이용자의 계정·이름·연락처·위치 좌표·입력한 검색어나 신고 내용은 포함하지 않음
서버 오류·성능 진단 정보 서버 장애와 응답 지연 분석, 보안·악용 대응 운영 장애 분석에 필요한 최소 기간 동안 보관 후 삭제 또는 익명화

3. 개인정보를 처리하는 방법

앱 설정과 최근 검색처럼 기기 안에서 처리하는 정보는 이용자의 기기에 저장됩니다. 시설 신고 제출, 서버 경로 검색, 선택형 ITX-청춘 경로 검색, 데이터 삭제 요청처럼 네트워크가 필요한 기능은 이용자가 해당 기능을 실행할 때 HTTPS로 전송됩니다.

4. 서버 경로 검색

배포 환경의 정본 지하철 경로 검색은 서비스 서버에서 수행합니다. 앱은 요청 식별자, 출발·도착역, 즉시 또는 예약 출발 기준, 시간표 또는 실시간 정보 사용 방식, 이동 조건, 최대 환승 수와 대안 수를 HTTPS 요청으로 보냅니다. 서버는 검증된 경로 데이터로 경로를 계산하며 필요한 데이터나 실시간 정보가 없거나 만료·불일치하면 이전·로컬 경로로 대체하지 않습니다.

경로 검색 요청 내용과 계산 결과는 요청 처리 중에만 사용하며 별도 검색 이력으로 저장하지 않습니다. 응답은 기기나 중간 서버에 저장되지 않도록 설정하며 요청을 이용자·기기·계정 정보와 연결하지 않습니다.

경로 검색을 시작할 때 앱은 Google Play Integrity에 경로 검색 요청을 확인하기 위한 값을 보내고, Google은 무결성 확인을 위해 앱 패키지 이름·버전·서명 인증서, 기기에 로그인된 Google Play 계정의 앱 구매(이용 권한) 상태와 기기 무결성 정보를 암호화해 처리합니다. 이 정보는 Google의 Play Integrity 고정 보관 정책을 따르며 Google이 제3자에게 전송하지 않습니다. 그 뒤 앱은 Google이 발급한 무결성 확인 결과와 128비트 임의 값을 서비스 서버로 전송하고, 서비스 서버는 검증을 위해 그 확인 결과를 Google에 확인을 요청합니다. 서비스 서버의 경로 세션·상태는 사용자·기기·계정 ID와 연결하지 않지만, 위 Google 처리 범위는 이 비연결 경계와 구분됩니다.

서비스 서버는 Google이 발급한 무결성 확인 결과 원본, 임의 값 원본, 세션 인증값 원본을 저장하지 않습니다. 검증 뒤 세션 인증값의 해시와 사용 범위, 발급·만료 시각, 요청 횟수를 논리적으로 10분 동안, 임의 값의 해시와 사용 시각·만료 시각을 논리적으로 2분 동안 저장합니다. 만료된 행은 이후 새 세션을 발급할 때 함께 물리 삭제하며 별도 고정 주기 삭제는 쓰지 않습니다.

선택형 ITX-청춘 경로 검색도 무결성 확인 결과 원본을 저장하지 않고, 검증 뒤 발급한 세션 인증값의 해시, 사용 범위, 발급·만료 시각, 요청 횟수를 논리적으로 10분 동안, 임의 값 원본 대신 그 해시를 논리적으로 2분 동안 저장합니다. 정상 동작 중 만료 데이터는 기본 5분 주기로 물리 삭제하므로 세션은 발급 후 약 15분 이내, 임의 값 해시는 수신 후 약 7분 이내 삭제됩니다. ITX-청춘 경로 요청에는 출발·도착역 ID, 출발 시각, 이동 유형과 이동 조건, 제약 방식, 실시간 사용 여부, 최대 환승 수, 대안 수가 포함됩니다.

경로 상태 저장소에는 경로 상태 식별자, 출발역·도착역 ID, 서버가 정한 운송 범위, 요청 출발 시각, 계산된 경로 결과, 시간표 데이터 식별자, 생성·도착 예정·만료 시각을 저장합니다. 이동 조건은 경로 결과의 보행 구간에도 포함되므로 일시 처리 정보로 분류하지 않습니다. 논리 보관 기간은 생성 시각부터 최소 30분, 최대 6시간(도착 예정 시각 30분 뒤까지)이며, 정상 동작 중 물리 삭제는 만료 뒤 5분 이내입니다.

서비스 서버는 위 경로 검색의 무결성 확인 결과 원본, 임의 값 원본, Google의 검증 응답 내용을 DB에 저장하거나 로그에 남기지 않으며, 서버 경로 검색 요청·응답을 별도 검색 이력으로 저장하지 않습니다. 선택형 ITX-청춘 경로 검색은 검색어 원문과 좌표를 요청으로 보내거나 저장하지 않습니다. 별도로 요청 제한용 게이트웨이는 접속 IP 주소(이진 표현)와 세션 인증값을 메모리에서 요청 횟수 계산용 키로만 처리합니다. 이 상태는 요청이 끝난 뒤에도 메모리에 남을 수 있어 일시 처리로 분류하지 않습니다. 고정 보관 기간은 없으며, 메모리가 부족하면 오래된 것부터 제거되고 최종적으로 게이트웨이 프로세스 종료 시 삭제됩니다. 설정값 10m은 보관 기간이 아니라 메모리 용량입니다. 이 키 값은 DB나 접속 로그에 저장하지 않습니다. 제한 응답 로그에는 고정 이벤트·범위·상태만 남고 키 값은 포함하지 않습니다. 세션과 경로 응답은 기기나 중간 서버에 저장되지 않도록 설정합니다.

5. 민감한 상태 정보

쉬운 지하철은 장애, 임신, 질병, 부상 여부를 증명하는 서류나 진단정보를 요구하지 않습니다. 앱은 사용자가 직접 선택한 이동 조건을 경로 안내에만 사용하며, 광고나 추적 목적으로 사용하지 않습니다.

6. 보관, 전송 및 파기

즐겨찾기, 최근 검색, 앱 설정, 신고 초안, 설치된 이동 정보 기록은 기본적으로 사용자 기기에 보관됩니다. 신고 제출, 서버 경로 검색, 선택형 ITX-청춘 경로 검색, 삭제 요청처럼 네트워크 전송이 필요한 경우 HTTPS를 사용합니다. 보관 목적이 끝나거나 삭제 요청 처리가 완료된 개인정보는 복구하기 어렵게 삭제하거나 식별 가능성을 줄입니다.

시설 신고의 사용자 연결, 신고 본문, 원본·썸네일 사진, 위치 좌표와 제출 식별값은 접수일부터 최대 1년 보관합니다. 운영 서버는 매일 보관 상한이 지난 신고를 확인해 해당 개인정보를 자동 삭제 또는 익명화하고, 역·시설·신고 유형·처리 상태처럼 개인을 식별하지 않는 운영 이력만 남깁니다. 이용자가 그 전에 데이터 삭제를 요청하면 확인 후 같은 항목을 지체 없이 처리합니다.

장애 복구를 위해 만든 제한된 PostgreSQL 백업 사본은 백업 생성일부터 최대 30일 보관하며, 백업 생성 시와 운영 환경의 일일 자동 작업에서 만료 사본을 삭제합니다. 데이터 삭제 요청 후에도 이미 생성된 백업 사본은 이 기간 안에서 장애 복구 목적으로만 제한하여 보관될 수 있습니다. 운영 객체 스토리지의 신고 사진은 별도 백업 사본을 만들지 않으며 운영 object의 보관·파기 기준을 그대로 적용합니다.

7. 제3자 제공, 처리 위탁 및 추적

쉬운 지하철은 개인정보나 민감정보를 판매하지 않습니다. 광고 목적의 tracking을 하지 않으며, 신고 사진과 위치 정보는 앱 기능 제공과 신고 검토 목적에만 사용합니다. 출구 정보가 표시되면 카카오맵 미리보기를 자동으로 불러오며 공개 역·출구 좌표와 지도 화면 범위를 카카오에 전달하지만 현재 위치는 사용하지 않습니다. 사용자가 화면의 전달 안내를 확인하고 출구 도보 길안내를 명시적으로 누르면 카카오맵 앱에는 현재 위치 시작 좌표와 목적지 좌표를, 카카오맵 웹에는 목적지 좌표를 전달합니다. 이 좌표는 쉬운 지하철 서버에 저장하지 않습니다. 서비스 운영에 필요한 범위에서만 Cloudflare, Oracle Cloud Infrastructure, Google Play Console, Google(Firebase Crashlytics) 같은 인프라와 스토어 운영·진단 도구를 사용할 수 있으며, 이 경우 해당 사업자는 서비스 제공, 보안, 저장, 배포, 진단 목적의 처리만 수행합니다.

앱이 비정상 종료되거나 앱이 처리한 오류가 발생하면 원인 분석을 위해 Google LLC의 Firebase Crashlytics로 진단 정보가 전송되어 처리됩니다. 전송 항목은 충돌 스택 트레이스, 예외 유형과 오류 종류 코드, 오류가 발생한 기능 구분, HTTP 상태 코드, 치명 여부, 발생 시각, 기기 모델·OS 이름과 버전·CPU 구조, 기기 상태(메모리와 저장 공간 용량, 화면 방향, 앱이 백그라운드에 있었는지 여부), 앱 버전, 앱 설치별로 부여되는 익명 설치 식별자(Crashlytics 설치 UUID, Firebase 설치 ID)와 세션 식별자입니다. Crashlytics 공식 안내는 IP 주소 수집 여부를 별도로 밝히지 않으나, 네트워크 전송 과정에서 접속 IP 주소가 Google 서버에 전달될 수 있으며 쉬운 지하철은 이를 수집하거나 저장하지 않습니다. 전송 전에 오류 메시지 원문과 파일 경로·URL 값은 제거하며 계정·이름·연락처·위치 좌표·검색어·신고 내용은 포함하지 않습니다. 쉬운 지하철은 이용자를 식별하는 값을 Crashlytics에 설정하지 않습니다. 이 정보는 앱 안정성 개선 목적으로만 사용하며 광고나 이용자 추적에는 사용하지 않습니다. Google은 해당 정보를 Crashlytics 서비스 제공을 위해 처리하며 Google의 개인정보처리방침이 함께 적용됩니다. 충돌 진단 전송은 정식 배포(release) 빌드에서만 이루어집니다.

개인정보의 국외 이전 (개인정보 보호법 제28조의8)

아래 국외 이전은 서비스 제공 계약의 이행을 위한 처리위탁·보관으로서, 개인정보 보호법 제28조의8 제1항 제3호에 따라 이 처리방침에 공개합니다.

Google Firebase Crashlytics (앱 오류 발생 시)

  • 이전받는 자: Google LLC (미국), Firebase Crashlytics 운영 사업자
  • 이전되는 항목: 충돌 스택 트레이스, 예외 유형과 오류 종류 코드, 오류가 발생한 기능 구분, HTTP 상태 코드, 치명 여부, 발생 시각, 기기 모델·OS 이름과 버전·CPU 구조, 기기 상태(메모리와 저장 공간 용량, 화면 방향, 앱이 백그라운드에 있었는지 여부), 앱 버전, 앱 설치별로 부여되는 익명 설치 식별자(Crashlytics 설치 UUID, Firebase 설치 ID)와 세션 식별자
  • 이전 일시와 방법: 앱이 비정상 종료되거나 처리된 오류가 발생할 때, 또는 그 뒤 앱을 다시 실행할 때 HTTPS 네트워크로 전송
  • 이용 목적과 보유 기간: 앱 오류 원인 분석과 안정성 개선, 수집일부터 90일 보관 후 삭제 절차 시작
  • 거부 방법과 거부 시 불이익: 현재 앱 안에는 충돌 진단 전송을 끄는 설정이 없습니다. 전송 중단이나 삭제를 원하면 privacy@aquilaxk.site로 요청할 수 있습니다. 앱을 삭제하면 이후 전송이 이루어지지 않습니다. 전송 여부는 앱 기능 이용에 영향을 주지 않습니다.

Google Play Integrity (경로 검색 시작 시)

  • 이전받는 자: Google LLC (미국), Google Play Integrity 서비스 운영 사업자
  • 이전되는 항목: 경로 검색 요청을 확인하기 위한 값, 앱 무결성 확인에 필요한 정보(앱 패키지 이름·버전·서명 인증서, 기기에 로그인된 Google Play 계정의 앱 구매(이용 권한) 상태, 기기 무결성 정보), 그리고 서비스 서버가 검증을 위해 Google에 보내는 Google이 발급한 무결성 확인 결과
  • 이전 일시와 방법: 경로 검색을 시작할 때 앱이 Google Play Integrity에 HTTPS로 전송하고, 서비스 서버가 같은 시점에 Google이 발급한 무결성 확인 결과를 Google에 보내 확인을 요청
  • 이용 목적과 보유 기간: 앱·기기 무결성과 라이선스 확인. Google은 이 정보를 암호화해 처리하며 제3자에게 전송하지 않고, Google의 고정 보관 정책에 따라 보관 후 삭제합니다(보관 기간 길이는 Google이 공개하지 않음).
  • 거부 방법과 거부 시 불이익: 경로 검색은 이 확인이 필요한 기능이므로 거부할 수 없으며, 확인 없이는 서버 경로 검색을 이용할 수 없습니다. 문의는 privacy@aquilaxk.site로 할 수 있습니다.

Cloudflare (앱이 서버에 요청할 때마다)

  • 이전받는 자: Cloudflare, Inc. (미국)
  • 이전되는 항목: 접속 IP 주소, 요청 정보(요청 경로, 시각, 기기·브라우저 정보)
  • 이전 일시와 방법: 앱이 서비스 서버에 요청할 때마다 HTTPS로 Cloudflare를 거쳐 중계
  • 이용 목적과 보유 기간: 서비스 전달과 보안 위협 차단. Cloudflare는 이 정보의 구체적인 보관 기간을 공개하지 않으며, 개인정보 처리 목적에 맞는 기간 또는 법적 의무 이행에 필요한 기간 동안 보관합니다.
  • 거부 방법과 거부 시 불이익: 서비스 이용에 필수여서 거부할 수 없으며, 거부하려면 서비스를 이용할 수 없습니다. 문의는 privacy@aquilaxk.site로 할 수 있습니다.

Oracle Cloud Infrastructure의 서비스 서버와 저장소는 모두 서울 리전(ap-seoul-1)에 있어 국외 이전에 해당하지 않습니다.

8. 개인위치정보의 처리

가까운 역 찾기에 사용하는 현재 위치는 기기에서만 처리합니다. 시설 신고에 위치를 선택해 첨부하면 운영자 서버에 전송되어 제2항과 제6항의 기준으로 처리됩니다. 출구 도보 길안내를 누르면 카카오맵 앱에는 현재 위치와 목적지 좌표가, 카카오맵 웹에는 목적지 좌표만 전달됩니다. 자세한 내용과 이용자의 권리는 위치정보 이용약관에서 확인할 수 있습니다.

9. 이용자 및 법정대리인의 권리

사용자는 개인정보 열람, 정정, 삭제, 처리 정지를 요청할 수 있습니다. 신고 데이터 삭제, 개인정보 문의, 보안 신고는 아래 주소로 요청할 수 있으며, 요청 확인에 필요한 최소 정보만 확인한 뒤 처리합니다.

  • 개인정보 및 삭제 요청: privacy@aquilaxk.site
  • 고객지원: support@aquilaxk.site
  • 보안 문의: security@aquilaxk.site

쉬운 지하철은 만 14세 미만 아동을 주 대상으로 하지 않습니다. 만 14세 미만 아동의 개인정보 처리 요청이 확인되면 법정대리인 확인 등 필요한 절차에 따라 처리합니다.

10. 안전성 확보 조치와 자동 처리 정보

개인정보는 접근 권한을 제한하고, 운영 로그에는 신고 receipt token, 사진 원본, 서명된 업로드 URL, 저장소 자격 증명을 남기지 않도록 관리합니다. 관리자 화면은 인증된 운영자만 접근할 수 있으며, 네트워크 전송에는 HTTPS를 사용합니다.

웹 기반 운영 경계에서는 보안과 요청 제한을 위해 IP 주소가 메모리 키로 처리될 수 있으나 DB 또는 access log에 저장하지 않습니다. 쉬운 지하철은 맞춤형 광고를 위한 쿠키나 행태정보 추적 도구를 사용하지 않습니다.
