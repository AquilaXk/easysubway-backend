# 쉬운 지하철 (EasySubway)

교통약자의 안전하고 끊김 없는 이동을 최우선으로 설계한 전국 도시철도·광역철도 길찾기 서비스입니다.

## 주요 기능

- **교통약자 맞춤형 경로 안내**: 휠체어·유모차·고령자 등 이동 조건에 맞춰 엘리베이터와 무단차 동선 위주의 지하철 경로를 안내합니다.
- **역사 접근성 및 편의시설 정보**: 역별 승강기·휠체어 리프트·경사로·승강장 단차 정보와 실시간 시설 가동 상태를 제공합니다.
- **실시간 열차 도착 및 막차 안내**: 실시간 열차 도착 예정 시각과 운행 공지, 환승 가능 여부와 막차 여유 정보를 함께 확인할 수 있습니다.
- **시설 고장·불편 제보**: 고장 난 승강기나 이동 불편 사항을 사진과 함께 제보해 더 정확한 역사 안내로 이어지도록 돕습니다.
