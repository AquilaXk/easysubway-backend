# EasySubway

Accessible nationwide subway and metropolitan rail route guidance designed for step-free travel.

## Key Capabilities

- **Step-Free Route Search**: Plans subway journeys tailored for wheelchair, stroller, senior, and elevator-first travel across Korean urban and metropolitan rail networks.
- **Station Accessibility & Facility Guidance**: Provides station elevator, wheelchair lift, ramp, platform gap, and accessible restroom status alongside real-time facility outage updates.
- **Realtime Arrivals & Last-Train Alerts**: Surfaces live train arrival estimates, service disruption notices, and last-train transfer feasibility.
- **Verified Facility Issue Reports**: Lets commuters report out-of-service elevators or accessibility barriers with optional photos so station accessibility information stays accurate.
