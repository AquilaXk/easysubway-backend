# EasySubway Backend

이동 제약을 고려한 경로, 실시간 열차 정보, 시설 제보를 EasySubway 모바일 앱에 제공하고 운영자가 데이터 품질을 관리할 수 있게 하는 백엔드입니다.

## 제공하는 기능

- **경로 탐색** — 출발·도착역, 출발 시각, 이동 제약과 환승 조건을 바탕으로 대안을 찾습니다. 배포 환경에서는 세션을 발급받은 v2 흐름으로 호출합니다.
- **실시간 열차 정보** — 역 도착 정보와 노선별 열차 위치를 앱에 전달합니다.
- **열차 검색** — 전국 여객열차 역 목록과 편도·왕복 열차편을 조회합니다.
- **시설 제보** — 사진을 첨부할 수 있는 제보를 접수하고, 접수 응답으로 받은 제보 ID와 접수 토큰으로 처리 상태를 확인·확인 완료할 수 있습니다.
- **운영 데이터 관리** — 역·시설·역사 구조·경로 데이터를 검수하고, 현장 확인과 데이터팩 후보·배포 채널을 관리합니다.
- **운영 현황** — 경로 피드백, 접근성·반복 고장 시설, 알림 발송, 데이터 수집 실패 등 서비스 품질 지표를 확인합니다.

## 현재 범위

- 모바일 앱 연동용 API와 인증된 운영 화면을 함께 제공합니다. 운영 기능은 일반 공개 API가 아닙니다.
- 경로 탐색은 배포 환경에서 `/api/v2/routes/session`으로 세션을 발급받은 뒤 `/api/v2/routes/search`를 호출하는 흐름만 도달할 수 있습니다. 세션 토큰은 `Authorization: Bearer`로 전달하고, 요청은 게이트웨이를 통과해야 합니다. v2 요청은 출발역·도착역과 함께 출발 시각(ISO offset 형식), 이동 유형, 이동 제약 조건, 실시간 반영 여부, 최대 환승 수(0~3), 대안 경로 수(1~3)를 필수로 받습니다.
- `/api/v1/routes/search`와 `/api/v2/routes/{routeSearchId}/refresh`는 로컬·개발 환경 전용입니다. `prod`·`staging`·`release`·`prod-like` 프로파일에서는 403으로 닫히므로 앱 연동 대상이 아닙니다.
- 실시간 조회는 `/api/v1/realtime/arrivals`, `/api/v1/realtime/train-positions`에서 제공하며, 현재 연동 대상은 서울 TOPIS입니다.
- 열차 검색은 `/api/v1/trains/stations`, `/api/v1/trains/search`에서 전국 여객열차 역 카탈로그와 열차편을 제공합니다.
- 제보는 제보 접수 → 상태 조회 → 처리 결과 확인 순서로 진행합니다. 사진을 첨부하지 않는 제보도 그대로 접수됩니다.
- 사진을 첨부할 때만 접수 전에 업로드 의도 생성과 사진 업로드를 거칩니다. 배포 환경에서는 의도 생성 응답의 서명 URL로 오브젝트 스토리지에 직접 업로드하며, 서버로 사진 본문을 보내는 `PUT /api/v1/report-uploads/{uploadId}`는 로컬·개발 환경 전용입니다. 익명 제보는 이 서명 URL 경로로만 사진을 첨부할 수 있습니다.
- 로그인한 사용자는 위 경로 대신 제보 접수 요청에 사진 파일명·형식과 본문을 직접 실어 보낼 수도 있습니다. 이때 사진은 JPEG·PNG·WebP만 허용하고 900KB·4096×4096 이내로 제한하며, 서버가 메타데이터를 제거하고 썸네일을 만들어 저장합니다.
- 익명 제보의 상태 조회(`GET /api/v1/reports/{reportId}`)와 확인 완료(`POST /api/v1/reports/{reportId}/confirm`)는 접수 응답의 제보 ID와 `X-Easysubway-Report-Receipt-Token` 헤더가 함께 필요합니다. 함께 내려주는 접수 번호는 사용자에게 보여주기 위한 값이며 조회 키로는 쓰지 않습니다. 로그인 사용자는 토큰 없이 본인 제보를 조회할 수 있습니다.
- 데이터 변경과 배포, 실시간 제공자 제어는 권한이 있는 운영자만 수행합니다.
